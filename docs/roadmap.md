# Roadmap Arquitetural

## Finalidade

Registrar próximos passos recomendados após a consolidação da arquitetura.

## Próximas etapas sugeridas

1. Validar instalação e build em ambiente com acesso ao npm registry.
2. Definir design tokens finais antes de criar componentes visuais complexos.
3. Definir autenticação e multiempresa antes de implementar módulos de negócio.
4. Definir contratos Supabase e políticas de segurança antes de CRUDs.
5. Implementar roteamento privado somente após o modelo de autenticação.
6. Adicionar testes automatizados conforme os primeiros fluxos forem implementados.

## Fora do escopo desta etapa

- Login.
- Dashboard funcional.
- CRUDs.
- Integração com banco.
- Supabase client.
- Regras de negócio.
